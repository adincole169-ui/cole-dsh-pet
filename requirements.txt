# 桌宠运行所需的第三方包
#
# 只有 PyQt5 是必需的。安装程序会建一个独立虚拟环境再装它，所以不会影响你系统里
# 已有的 Python 环境。
#
# 为什么限定 <6：代码里有几处与 Qt5 API 绑定的写法（`sip.voidptr.setsize`、
# 1bpp 掩膜的位语义等），PyQt6 改了这些接口。5.15 是 Qt5 的最后一个系列，
# 已在 PyQt5 5.9.2 与 5.15.11 两个版本上通过全部自检。
PyQt5>=5.15,<6

# numpy 是**可选**的：有它时输入掩膜的逐像素阈值运算快很多（137ms → 几毫秒），
# 没有时自动退回纯 Python 实现（慢一些，但功能完全一样，自检已验证）。
# 想更流畅可以取消下面这行的注释：
# numpy
