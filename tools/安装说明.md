# 大肥鱼桌宠 + 对话界面背景

一个能跟 DeepSeek Harness（DSH）联动的桌面宠物：它会待在桌面上、自己走动，
DSH 干活时切到"忙碌"动画，干完了蹦一下，出错时叹口气；你还能右键让它碎碎念或跟它聊天。
另外附带一个 DSH 对话界面的**背景 + 启动动画**。

## 这个包里有什么

```
dsh-pet-share\
  install.ps1        一键安装（双击或按下面命令跑）
  uninstall.ps1      卸载
  安装说明.md         本文件
  profile-plugin\    「对话界面背景 + 启动动画」插件（纯 JS，自包含）
  pet\               桌宠本体（Python）
```

## 安装

1. 把整个目录解压到任意位置（**不要**放在需要管理员权限的目录里，比如 `C:\Program Files`）
2. 在这个目录里打开 PowerShell，运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

> 直接双击 `install.ps1` 有时会没反应——那是 Windows 的脚本执行策略。用上面的命令最稳。

安装程序会做这些：

| 步骤 | 说明 |
|---|---|
| 检查 DSH | 需要你**先启动过一次 DSH**（它才会建出 profile 目录） |
| 装背景插件 | 复制到 DSH 的 profile，并在配置里登记一行 |
| 装桌宠 | 复制到 `%LOCALAPPDATA%\DshPet`（可用 `-PetDir` 改） |
| 建虚拟环境 | 在桌宠目录里建 `.venv` 并装 PyQt5，**不动你系统的 Python** |
| 建快捷方式 | 桌面上的「大肥鱼」 |
| 开机自启 | 会问你，默认不装 |

### 前置条件

- **Windows 10/11**
- **Python 3.8 或更高**（[python.org](https://www.python.org/downloads/) 下载，安装时勾选 *Add python.exe to PATH*）
- **DSH**（DeepSeek Harness），并且至少启动过一次
- 装 PyQt5 时需要联网（约 50MB）

**不需要** ffmpeg、不需要 Pillow、不需要 npm——帧素材已经随包提供。

## 用起来

桌面上的「大肥鱼」双击启动。右键它有很多菜单：

| 菜单项 | 作用 |
|---|---|
| 模式 → 自由活动 / 原地待着 | 是否允许它自己走开 |
| 大小 → 160/240/320/480 | 换尺寸 |
| 现在碎碎念一句 | 让它说一句话（走 DSH 的模型） |
| 和我说句话 | 弹输入框跟它聊天 |
| 走走看 | 随机走一段 |
| 点播动画 | 106 个动作任选（吃东西、玩耍、工作时节…） |
| 总在最前 / 回到初始位置 / 隐藏 | 位置与层级 |
| 和 DSH 联动 | 开关：工作状态、余额分档、碎碎念、通知 |

拖动它可以换位置；单击它会触发回应动作。

### 跟 DSH 的联动

桌宠会读 DSH 的会话状态，并把这些映射成动画：

| DSH 里发生的事 | 桌宠的反应 |
|---|---|
| 一轮开始、正在思考 | 思考动画 |
| 调用工具 | 忙碌动画 |
| 工具返回、在整理 | 归档动画 |
| 一轮干完（用过工具） | 蹦一下庆祝 |
| 出错 | 叹气 |
| 余额/用量分档 | `余额-*` 那组动画 |
| 你不在看 DSH 时干完活 | 弹一条系统通知 |

联动是**可选**的：桌宠自己持有显示服务，DSH 只是往里投状态。DSH 没开、或者关掉联动，
桌宠依然能自己跑（待机、漫游、拖拽、点播动画都照常）。

### 背景 + 启动动画

装好并**重启 DSH** 后，对话界面会带上背景，启动时播一小段动画。

## 配置

改 `%LOCALAPPDATA%\DshPet\config.jsonc`（JSONC，带注释，改完重启桌宠生效）。

最常改的几项：

```jsonc
{
  "size": 320,                    // 默认大小
  "gravity": 0,                   // 0 = 不要重力（不会自己沉到屏幕底部）
  "pets": [{
    "fixedEnabled": false,        // true = 启动就"原地待着"
    "whisperEnabled": true,       // 自动碎碎念
    "workStatusEnabled": true,    // 跟着 DSH 会话状态切动画
    "balanceEnabled": true,       // 用余额驱动 余额-* 动画
    "notificationsEnabled": true  // 系统通知
  }]
}
```

## 卸载

```powershell
powershell -ExecutionPolicy Bypass -File .\uninstall.ps1
```

会停掉桌宠、删掉程序目录与快捷方式、移除开机自启，并问你是否也摘掉背景插件。
**不会**动 DSH profile 里的其它任何配置。

## 常见问题

**双击快捷方式没反应？**
看一下 `%LOCALAPPDATA%\DshPet\logs\pet-run.log` 的最后几行——正常退出和崩溃在里面分得很清楚。
如果提示"已有一只在运行"，那是防止开出两只，属正常。

**桌宠不见了？**
右键托盘图标（在任务栏右下角），或用 `/place` 那套恢复接口。极端情况下
（Qt 分层窗口合成失败）可以重跑桌宠，它会把自己挪回屏幕中央。

**背景没生效？**
插件**没有热重载**：装完必须**完全重启 DSH**。改了插件的 `.js` 之后也一样。

**碎碎念/对话没反应？**
需要 DSH 在运行，且「和 DSH 联动」是开着的。失败原因会直接显示在气泡上。

**想让它别自己走动？**
右键 → 模式 → 原地待着。

**内存占用？**
常驻约 150MB（内存里保留最近的几个动画，按 LRU 淘汰）。磁盘上 `frames\` 约 2GB
（106 个动画的 PNG 帧）——如果你想省磁盘，可以删掉 `frames\`，
代价是首次播某个动画要现场解码（每个约 20 秒），并且那时需要 ffmpeg 和 Pillow。

**杀毒软件报警？**
桌宠是个 Python 脚本，会监听本地 127.0.0.1:8899 用于接收 DSH 的状态；
安装程序会写一个注册表项（开机自启，可拒绝）和一个桌面快捷方式。
如果报警，选择允许即可——这些行为都是它正常工作所必需的。
