# 大肥鱼桌宠 · 更新说明

适用于**已经装过旧版本**的用户。如果你还没装过，直接用完整包里的
`install.ps1` 全新安装即可，不需要看这份文档。

---

## 这次更新了什么

上一次发布之后修了 4 个问题、换了一套更清晰的素材。

### 1. 任务栏里的名字改对了

**症状**：任务栏上显示的是「蓝毛小女仆」，不是「大肥鱼」。

**原因**：窗口标题用的是配置里的**内部物种名**（`name`），而那个名字同时也是
素材目录和物种配置的键，不能随便改。结果同一只宠物在三个地方有三个名字：
任务栏用内部名、托盘提示是个写死的字符串、系统通知又是一个写死的常量。

**现在**：新增 `displayName` 配置项，任务栏、托盘提示、系统通知**统一**用它。
默认 `大肥鱼`。

```jsonc
"name": "蓝毛小女仆",        // 内部物种名（素材目录键，别改）
"displayName": "大肥鱼",      // 给用户看的名字（改这个）
```

### 2. 画面更清晰了（换了原生分辨率素材）

**症状**：宠物看着有点糊。

**原因**：之前打包的帧是**从 640 缩到 480** 的，显示时又被放大回 640 —— 多了一次
不必要的缩放，边缘会变软。而这套素材的原生分辨率就是 640。

**现在**：全部 106 个动画重新解码成**原生 640**，显示时 1:1 无缩放。

| | 之前 | 现在 |
|---|---|---|
| 帧宽 | 480（缩过的） | **640（原生）** |
| 显示缩放 | 放大 1.33 倍 | **1:1** |
| 素材体积 | 1.5 GB | 2.6 GB |

> 说明：这套素材的画风本身偏柔和，这是上游原画的特性，不是打包造成的。本次改动
> 消除了「多一次缩放」这一层损失，是这套素材能达到的最佳状态。

### 3. 现在能真正放到屏幕最右边了

**症状**：拖动宠物，明明已经拖到最右，但角色离屏幕边缘还差一截。

**原因**：窗口比角色宽。一帧画面是 640×360 的整幅画，角色只占中间约 35%，
两侧各有约 107 像素的**透明留白**。旧代码拿**窗口**去贴屏幕边，贴住的是那圈看不见的
留白，角色于是停在离屏幕边约 107px 处。

**现在**：贴边、居中、初始摆放全部改成按**角色的实际占位**计算。拖到最右时角色
正好贴住屏幕边缘（留白被推到屏幕外）。

### 4. 初始位置修正到右下角

**症状**：配置里写的是右下角，但启动后出现在**右上角**。

**原因**：位置计算写成「只要 `corner` 含 top **或** 没开重力就摆到顶部」。而配置里
是 `bottom-right` + `gravity: 0`（不要重力），于是被判成"顶部"。重力只该决定
"随后会不会往下掉"，不该决定"摆在哪一角"。

**现在**：上下完全按 `corner` 决定。

### 附带

- README 补了 3 条排查记录（内部名与显示名、反复踩的引号/编码坑、窗口矩形与角色占位的区别）
- `tools/` 里多带了几个自检脚本（`doctor.py` / `check_syntax.py` 与 3 个自检），
  遇到问题可以自己先跑
- **不影响安装方式**：`install.ps1` 与 `uninstall.ps1` 没有变化

## 怎么更新

更新用的是**更新补丁**（`dsh-pet-update.zip`），不是完整包。解压后按下面任一种方式做。

### 方式一：双击 `更新.cmd`（最简单）

解压补丁，**双击 `更新.cmd`**。它会自动更新，结束时停住让你看结果。

### 方式二：在 PowerShell 里跑

```powershell
powershell -ExecutionPolicy Bypass -File .\update.ps1
```

| 参数 | 作用 |
|---|---|
| （无） | 正常更新，会先备份你的配置 |
| `-DryRun` | **只预演**，不改动任何文件（想先看看会做什么就用它） |
| `-NonInteractive` | 不弹任何询问（给智能体用） |
| `-PetDir "路径"` | 手动指定桌宠目录（自动探测失败时用） |

它做的事：

1. 检查当前版本（是不是旧版、帧素材是 480 还是 640）
2. 停掉正在运行的桌宠
3. **备份你的 `config.jsonc`**（备份名带时间戳）
4. 覆盖 4 个代码文件 + 全部帧素材（约 25400 个文件，2.6 GB）
5. 校验结果，写出 `update-status.json`

**不动虚拟环境、不动桌面快捷方式、不动 DSH 插件、不动开机自启。**

### 方式三：用完整包重装（补丁用着不顺时）

用新版完整包重跑 `install.ps1`。它会把桌宠目录整体覆盖、重建虚拟环境与快捷方式。
**你的 `config.jsonc` 会被覆盖**，所以先备份：

```powershell
Copy-Item "$env:LOCALAPPDATA\DshPet\config.jsonc" "$env:USERPROFILE\Desktop\config-backup.jsonc"
```

装完把备份里你改过的项对照着填回新配置（新配置里多了 `displayName`）。

### 更新之后

1. **关掉桌宠再重开**（托盘图标右键 → 退出，然后双击桌面快捷方式）。
   帧素材和代码都是启动时读的，不重启不生效。
2. 首次启动可能要等几秒（新的 2.6 GB 帧素材要建立索引）。
3. 背景插件这次**没有改动**，不需要重启 DSH。

## 怎么确认更新成功

### 看任务栏

鼠标悬停在桌宠上，或看任务栏 —— 应该显示「**大肥鱼**」。

### 命令行核对

```powershell
& "$env:LOCALAPPDATA\DshPet\.venv\Scripts\python.exe" -X utf8 "$env:LOCALAPPDATA\DshPet\main.py" --status
```

输出的第二行应该是：

```
  蓝毛小女仆 (id=main, 显示名=大肥鱼, size=320, display=both)
                ^^^^^^^^^^^^^^ 有这一段就是新的
```

旧版没有「显示名=大肥鱼」。

### 看帧素材是不是原生 640

```powershell
& "$env:LOCALAPPDATA\DshPet\.venv\Scripts\python.exe" -c "import struct,glob; p=sorted(glob.glob(r'$env:LOCALAPPDATA\DshPet\frames\*\0001.png'))[0]; d=open(p,'rb').read(24); print('%dx%d' % struct.unpack('>II', d[16:24]))"
```

应当输出 **640x360**。如果是 480x270，说明帧素材还是旧的。

### 拖动测试

把宠物拖到屏幕最右边 —— 角色应该**贴住屏幕边缘**，而不是停在离边一截的地方。

## 回退

更新脚本会把你的 `config.jsonc` 备份成 `config.jsonc.bak-<时间戳>`，放在桌宠目录里。
只想回退配置就把那个文件改回 `config.jsonc`。

整个桌宠想重来，运行 `uninstall.ps1` 再重新安装即可。
